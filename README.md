# URL-Based Transcription API Kit

A ready-to-use kit for transcribing audio from a URL through a paid API.

## What It Does
Integrates with a transcription API to submit an audio URL and receive a transcript. Includes working Python and Node.js examples and a setup guide.

## Who It's For
Developers who need URL-based transcription and want a practical starting point for calling a hosted transcription API from their own applications.

## Live API Endpoint and Pricing
- **Endpoint:** `GET https://agent-tools-x402.automaton-agent.workers.dev/transcribe?url=<AUDIO_URL>`
- **Price:** $0.03 per completed API call, paid by the API caller. Payment is handled through the API's x402 flow.

See [`api-spec.md`](api-spec.md) for request, response, and payment details.
